# Animation vocabulary

Read the relevant category in [the glossary](references/glossary.md). Lead with
the best-matching term and a short explanation tied to what the user described.
Give alternatives only when they distinguish plausible interpretations.

Treat the glossary as a vocabulary aid, not an exhaustive authority. Explain
an approximation or consult the relevant library documentation when the term
is missing. A naming question does not require designing or implementing motion.

Dev Kit maintains this fork of Emil Kowalski's glossary. See [NOTICE](NOTICE)
and [LICENSE](LICENSE).
