# Design engineering

Start from the requested interaction and the product's existing design language.
Look for details that affect usability: input feedback, focus, hover continuity,
content changes, and defaults. Preserve deliberate product choices.

- Building or polishing a component: [component details](references/components.md).
- Choosing or evaluating motion: [motion decisions](references/motion.md).

Use the running interface to judge the result. Report specific observations and
tradeoffs in the format that suits the task. Aesthetic preferences are guidance,
not automatic review failures. Implement changes when requested and keep an
audit read-only when that is the assignment.

Dev Kit maintains this fork of Emil Kowalski's guide. See [NOTICE](NOTICE) and
[LICENSE](LICENSE).
