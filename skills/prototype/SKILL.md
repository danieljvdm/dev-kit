# Prototype alternatives

Use this skill when explicitly requested. Build distinct responses to the brief
and let the user compare them in context. Follow the requested scope; narrow a
large exploration only when a material constraint requires it.

- Choosing and building alternatives: [exploration](references/exploration.md).
- Implementing the comparison control: [picker](references/picker.md).
- Integrating a selected alternative: [promotion](references/promotion.md).

Keep exploration isolated from production integration until the user chooses
or delegates the choice. Use the project's tokens and realistic content. Judge
each alternative at the size and in the context where it would be used.

Dev Kit maintains this fork of Emil Kowalski's workflow. See [NOTICE](NOTICE)
and [LICENSE](LICENSE).
